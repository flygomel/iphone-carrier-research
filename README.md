# 5G на iPhone в Беларуси — страновой эксперимент

Основной сценарий временно меняет **один ключ `Show5GSwitch` в страновом overlay Belarus**, сохраняет оригинал и проверяет запись. Затем пользователь перезагружает iPhone. **CarrierLab и Docomo не устанавливаются; прошивка не скачивается.**

Проверенный исследовательский профиль: **iPhone 17 Pro Max (`iPhone18,2`), iOS 27.2 / 24B5084k, A1 72.7.1 + life 72.7**, Mac с Apple Silicon. Жёсткого списка моделей и сборок нет. Другие устройства и сборки не проверены; доступность метода на них не гарантирована. Это эксперимент, не гарантия услуг оператора.

В опыте после сброса сети меню вернулось на обеих линиях, life подключился к 5G; A1 оставался на LTE. Пользователь подтвердил сохранение после второй перезагрузки. После первой перезагрузки страновой файл уже совпал с исходным (`false`). Телефон ранее участвовал в опытах CarrierLab: минимальный сценарий **ещё не проверен на устройстве без такой истории**. Сброс сети не требуется для обычного запуска; он применялся для сравнения опытов и не гарантирует чистого состояния.

## Запустить

1. Скачайте ZIP репозитория и распакуйте на Mac.
2. Установите Python 3.12 и Command Line Tools (`xcode-select --install`), если их ещё нет.
3. Подключите один iPhone кабелем, разблокируйте кодом и подтвердите доверие. Закройте синхронизацию Finder/Books.
4. В Terminal перейдите в папку проекта и выполните:

```sh
zsh Start.command
```

5. Окно ожидает iPhone и показывает подключение/отключение. Когда телефон готов, нажмите Enter для продолжения (или `n` для отмены). Не отключайте телефон до сообщения о завершении.
6. Перезагрузите iPhone вручную. Проверьте меню «Голос и данные», интернет и звонки на обеих SIM. Для life выберите её для мобильных данных и отключите Wi-Fi. Field Test: `*3001#12345#*`.
7. После разблокировки проверьте файл:

```sh
zsh Start.command --inspect
```

`Show5GSwitch: false` после перезагрузки — наблюдавшееся поведение, не повод автоматически повторять применение. Поддержка меню и реальная сеть проверяются отдельно. После успешной проверки повторите перезагрузку для проверки устойчивости.

Первый запуск устанавливает закреплённые Python-зависимости и собирает USB-помощники. Многогигабайтных загрузок и требования 40 ГБ в основном сценарии больше нет. Неподписанный скачанный скрипт может блокироваться при двойном щелчке; запускайте командой выше, не отключая защиту macOS целиком.

## Резервные копии и возврат

Все данные находятся в `private/country-…/`. Сохраните **всю папку private**, не публикуйте её: там данные устройства и резервные копии Books.

```sh
zsh Start.command --restore
```

Для запуска и `--inspect` нужна хотя бы одна активная белорусская SIM. Версии операторских пакетов и обязательная пара A1/life не проверяются. `--restore` использует резервную копию того же устройства и сборки, поэтому SIM для возврата не нужна.

Возврат использует точные исходные байты из резервной копии этого устройства и сборки. Если другие ключи файла изменились, возврат останавливается, чтобы не затереть эти изменения. Если файл побайтово совпадает с копией, повторной записи содержимого нет. Возврат файла не обещает отменить все ранее сохранённые сетевые предпочтения.

Для поиска активного файла временно переносится и возвращается каталог страновых предпочтений; ссылки внутри читаются без перехода по ним. Даже `--inspect` временно перемещает каталог Overlay и данные Books, затем возвращает их. Все файлы Overlay резервируются; после записи проверяется, что изменён только выбранный файл. Это **не read-only USB-диагностика**. При ошибке не удаляйте private и не повторяйте запись: незавершённая операция блокирует новый запуск. Автоматическое восстановление после любого отключения USB/питания не гарантируется; может понадобиться разбор сохранённого журнала. Не сбрасывайте настройки сети во время операции.

## Что проверяет код

- Фактическую модель и сборку для привязки операции и копии к подключённому устройству; фиксированного списка совместимости нет.
- Ссылки активных белорусских SIM на страновой overlay: имя файла определяется автоматически. Все выбранные линии должны указывать на один файл.
- Структуру Belarus plist и булевый Show5GSwitch. SHA-256 сохраняется для проверки целостности копии, заранее заданных хешей нет.
- Сохранение оригинала до записи, изменение только `Show5GSwitch`.
- Возврат файла протоколом, восстановление Books и отдельное повторное чтение после применения.

Код не меняет операторский каталог и не перезагружает телефон автоматически. Результат программы не доказывает регистрацию NR; её нужно проверить на устройстве. Если активные белорусские SIM указывают на разные файлы, программа останавливается до изменения настройки.

## Обновление со старых версий

В текущей версии только страновой сценарий. CarrierLab, IPCC, загрузчик прошивок и экспериментальные режимы удалены. Их исходники и инструкции остаются в [теге v0.2.0-rc.3](https://github.com/flygomel/iphone-carrier-research/tree/v0.2.0-rc.3).

Папку `private` не удаляйте. Если прежняя операция не завершена, сначала восстановите её средствами той версии, которой она была начата. Новый запуск сохраняет блокировку незавершённых старых операций; их каталоги не конвертируются автоматически. Флаги `--experimental`, `--legacy-carrierlab` и `--rollback` теперь отклоняются.

## Структура

- `Start.command`, `launch.py` — запуск.
- `country.py` — один страновой ключ, проверка и возврат.
- `device.py` — USB-диагностика и проверки устройства.
- `file_transport.py` — перенос файла, резервирование и восстановление Books.
- `vendor/airlift/` — исходники USB-помощников и лицензия.
- `tests/` — проверки записи, транспорта и восстановления.

## Проверки

```sh
python3.12 -m unittest discover -s tests -v
make -C vendor/airlift test
```

Детали и ограничения: [VALIDATION.md](VALIDATION.md). Apple-файлы и персональные резервные копии не входят в репозиторий. MIT-лицензия относится к коду проекта; лицензия USB-помощников сохранена в vendor.
