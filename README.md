# CarrierLab для iPhone — исследование 5G в Беларуси

Запуск с Mac, который сохраняет операторский каталог iPhone, применяет оригинальные файлы CarrierLab, меняет привязку A1 и проверяет результат повторным чтением. Исходники открыты; Apple-файлы скачиваются отдельно и не входят в репозиторий.

**Экспериментальная версия для одной конфигурации:** iPhone 17 Pro Max (`iPhone18,2`), iOS **27.2, сборка 24B5084k**, две SIM — A1 Беларусь и life. На другой модели, сборке или наборе SIM программа остановится до записи. Windows и Linux не поддерживаются.

В исходном опыте меню 5G появилось для обеих линий, life показал NR n7, A1 оставался на LTE. Применение CarrierLab не гарантирует доступ к 5G, VoLTE или другим услугам оператора. Программа проверяет файлы и выбранный пакет; сетевой результат проверяется отдельно на телефоне.

## Запустить

1. Скачайте ZIP этого репозитория через **Code → Download ZIP**, распакуйте на Mac.
2. Установите [Python 3.12](https://www.python.org/downloads/macos/). Если Command Line Tools ещё нет, выполните в Terminal `xcode-select --install` и дождитесь завершения.
3. Подключите **один** iPhone кабелем с передачей данных, разблокируйте его и подтвердите доверие в Finder/iPhone. Закройте синхронизацию Finder и Books.
4. Откройте `Start.command`. Если macOS блокирует открытие скачанного файла, используйте Terminal: напечатайте `cd `, перетащите папку проекта, нажмите Enter, затем выполните `zsh Start.command`.
5. Программа покажет найденный телефон и описание изменений. Введите **ДА**, чтобы начать.
6. Оставьте телефон подключённым и разблокированным до сообщения о завершении.

Первый запуск устанавливает закреплённые Python-зависимости, собирает два помощника и скачивает оригинальные пакеты Apple. Извлечение из прошивки может потребовать нескольких ГБ трафика и десятков минут; перед ним проверяется наличие 40 ГБ свободного места. Последующие запуски проверяют и используют локальные файлы.

Без графического запуска:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --require-hashes -r requirements.lock
python launch.py
```

Все резервные копии и результаты находятся в `private/`. **Сохраните эту папку для отката.** Она содержит данные устройства и Books; не публикуйте её. Не запускайте второй экземпляр и не отключайте кабель во время переноса каталога.

## Что делает программа

1. Проверяет точную модель, сборку и SIM.
2. Получает оригинальные CarrierLab/A1 из официального IPSW, Docomo — с сервера Apple. Сверяет каждый используемый файл с закреплённым SHA-256. Это проверка известных байтов, а не самостоятельная криптографическая проверка Apple-подписи.
3. Проверяет транспорт на новом временном файле, восстанавливает данные Books.
4. Сохраняет исходный операторский каталог. Для нового применения устанавливает оригинальные A1 и Docomo, затем получает свежий исходный снимок.
5. Сохраняет все его файлы, добавляет CarrierLab и меняет только `25701 → CarrierLab.bundle`. Пакет life не редактируется.
6. Проверяет записанный каталог независимым чтением, устанавливает оригинальный Docomo для перечитывания настроек.
7. Проверяет выбор CarrierLab для A1 через iOS, повторно сравнивает каталог и сохраняет `private/launch-…/result.json`.

Если такой же CarrierLab уже применён, повторной замены каталога не происходит: программа проверяет оригинальные байты, запрашивает перечитывание и проверяет результат.

## Как понять результат

Успешный отчёт содержит:

```json
{
  "phase": "complete",
  "protected_catalog_verified": true,
  "carrier_selected": true,
  "network_5g_verified": false
}
```

Последнее поле намеренно остаётся `false`: программа не измеряет текущий радиоканал.

На iPhone:

1. Выберите life для мобильных данных, отключите Wi-Fi, проверьте интернет.
2. Откройте «Сотовая связь → нужная SIM → Голос и данные». Если есть выбор 5G, включите его.
3. В приложении «Телефон» наберите `*3001#12345#*`, нажмите вызов. Выберите нужную линию и проверьте сведения NR/5G. Один значок или наличие меню не доказывают передачу данных через 5G.
4. Проверьте обычные звонки и интернет для обеих SIM. Затем перезагрузите iPhone вручную и повторите проверки. Программа сама телефон не перезагружает.

В исходном эксперименте наблюдались life: n7 / 20 МГц / NRARFCN 527070 и LTE B3; A1: LTE B7. Нельзя считать этот результат доказательством, что A1 отключил 5G во всей сети, или обещанием такого же результата в другом месте.

## Откат каталога

После нового применения программа печатает команду с **вашей** папкой запуска. Например, в активированном Python-окружении:

```bash
python launch.py --rollback private/launch-ВАШ_НОМЕР
```

Замените `launch-ВАШ_НОМЕР` реальным именем из результата. Откат проверяет, что текущий каталог совпадает с записанным вариантом, возвращает сохранённый каталог перед применением CarrierLab, запрашивает перечитывание и проверяет результат.

Это откат операторского каталога, а не полный образ телефона. Он не отменяет все внутренние эффекты установки IPCC, не восстанавливает прежние права/владельцев/xattrs и не гарантирует исчезновение меню 5G. Каталог перед установкой A1/Docomo тоже сохраняется отдельно как `initial_snapshot`.

## Если запуск остановился

Не удаляйте `private/` и не повторяйте применение вслепую. Незавершённая операция блокирует следующую запись. Повторно подключите и разблокируйте телефон; найдите папку, указанную в сообщении.

Для обычного экспорта/возврата:

```bash
python catalog.py recover --run private/catalog-ВАШ_НОМЕР --confirmed-device-write
```

Для операции применения/отката:

```bash
python transaction.py recover --run private/catalog-ВАШ_НОМЕР --confirmed-device-write
```

Тип указан в `state.json`: `operation: catalog_transaction` требует второй команды. При незавершённом дочернем `verification_run` сначала восстанавливается он. Не редактируйте журналы, чтобы обойти блокировку.

Если установка IPCC завершилась без ответа `Complete`, она не повторяется автоматически: сначала требуется разобрать сохранённый результат. Сброс настроек сети не является восстановлением файлов каталога.

## Что проверено

Подробные результаты и обнаруженные сбои: [VALIDATION.md](VALIDATION.md). Транспорт, каталоги и восстановление: [docs/CATALOG.md](docs/CATALOG.md).

Проверки выполнялись на одном исследовательском iPhone. Повторяемость появления 5G на ранее неизменённом устройстве и минимальная достаточная последовательность не установлены. Поэтому выпуск обозначен предварительным, а не универсальным активатором.

Офлайн-тесты без телефона и Python-зависимостей:

```bash
python3.12 -m unittest discover -s tests -v
```

Read-only диагностика отдельно от запуска:

```bash
python carrier.py doctor --out private/device.json
```

`activation_supported: false` в этом отчёте означает отсутствие гарантированной активации сети; модель/сборка проверяются отдельным полем. Для повторного отчёта используйте новое имя файла.
