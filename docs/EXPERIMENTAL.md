# Экспериментальный режим — без предварительного испытания конфигурации

Начиная с 0.2.0-rc.2 можно пробовать другие модели, сборки и операторов. Это **разрешение эксперимента**, не подтверждение совместимости. Запись и восстановление на неизвестной прошивке могут не работать; возможна потеря мобильной связи. Наличие резервной копии не гарантирует возможность её вернуть.

Обычный режим сохраняет прежние ограничения. Экспериментальный включается отдельно:

```bash
zsh Start.command --experimental
```

После подготовки выберите MCC+MNC оператора, если линий несколько, и для записи введите **ЭКСПЕРИМЕНТ**. Обычный `--yes` это подтверждение не заменяет. Для явно подтверждённого автоматизированного запуска предусмотрен отдельный `--accept-experimental`.

## Что определяется автоматически

- Фактически подключённый USB iPhone, модель, точная версия/сборка, аппаратная плата, MCC/MNC имеющихся линий.
- URL точной прошивки из каталога IPSW.me; сама прошивка загружается только по HTTPS с допустимых серверов Apple. Индекс служит поиском, а не доказательством совместимости.
- `BuildManifest.plist` Apple: должны совпасть модель, сборка, версия и аппаратная плата.
- CarrierLab и единственный подходящий набор overrides для этой платы. Формат должен содержать Info/carrier, plist/PRI overrides и соответствующие файлы signatures. Присутствие signatures не равно криптографической проверке Apple-подписи.

Для бета-сборки, которой нет в индексе, задайте официальный Apple URL:

```bash
zsh Start.command --experimental --ipsw-url 'https://updates.cdn-apple.com/ПУТЬ_К_ТОЧНОЙ_ПРОШИВКЕ.ipsw'
```

Универсальной совместимости нет: отсутствующая прошивка, неподходящая структура CarrierLab, отсутствие исходной операторской привязки, неоднозначная SIM или отказ транспорта останавливают запуск. iPhone до поколения с аппаратной поддержкой 5G отклоняются. Две линии с одинаковым MCC/MNC пока не поддерживаются: каталог не позволяет менять их по отдельности.

## Подготовка без записи на iPhone

```bash
.venv/bin/python launch.py --experimental --sim 25701 --prepare-only
```

`25701` — пример для A1; программа покажет коды фактически обнаруженных SIM. Подготовка читает устройство и загружает файлы на Mac, но не запускает canary, не перемещает каталог и не устанавливает IPCC. Прошивка может требовать десятков ГБ трафика/места. Контрольные суммы полученных файлов и привязка к устройству сохраняются в `private/experimental-…/`.

Продолжить подготовленный запуск:

```bash
.venv/bin/python launch.py --experimental --prepared private/experimental-ВАШ_НОМЕР
```

Папку нельзя переносить для применения на другой iPhone. Перед записью повторно проверяются устройство, сборка, плата, выбранный оператор и сохранённые файлы.

## Что меняется

Сначала выполняется пробная запись нового временного файла с возвратом Books. Это проверка отдельного транспорта, а не доказательство безопасности последующих операций. Затем сохраняется текущий каталог, добавляются оригинальные файлы CarrierLab, меняется только существующая ссылка выбранного MCC/MNC. Остальные файлы и ссылки сохраняются. Другой ранее установленный CarrierLab не перезаписывается.

Запись проверяется независимым чтением. В экспериментальном режиме **не устанавливаются A1 или Docomo из профиля iPhone18,2**. После завершения перезагрузите телефон вручную и проверьте интернет, звонки, меню и Field Test. Перечитывание настроек и доступ к 5G автоматически не подтверждаются:

```json
{
  "phase": "catalog_verified",
  "experimental": true,
  "compatibility_verified": false,
  "network_5g_verified": false,
  "reload_verified": false
}
```

## Откат и остановка

После завершённого применения вернуть исходный каталог:

```bash
.venv/bin/python launch.py --experimental --rollback private/experimental-ВАШ_НОМЕР
```

Откат требует точного совпадения текущего каталога с записанным вариантом. При изменениях он останавливается, сохраняя копии. Это откат файлов и ссылок, не полный образ iPhone или восстановление всех свойств файловой системы.

Если операция прервалась, **не удаляйте private**. В `progress.json` подготовленной папки указаны созданные каталоговые операции. Восстановить соответствующую операцию с той же привязкой устройства:

```bash
.venv/bin/python launch.py --experimental \
  --prepared private/experimental-ВАШ_НОМЕР \
  --recover private/catalog-НОМЕР_ОПЕРАЦИИ
```

Если есть незавершённый `verification_run`, сначала восстанавливается он. Не все состояния автоматически восстанавливаются: отсутствие проверенной копии, неизвестный результат переноса или изменившийся каталог требуют отдельного разбора. Это прямо отражено в статусе режима.

## Что проверено для этого режима

Офлайн-проверки привязки устройства, выбора платы, манифеста, сохранности других операторов и отказа при чужом CarrierLab. Проверка native-ограничителя выполняется без устройства на синтетических профилях. На исследовательском iPhone проверена только подготовка без записи с получением совпадающего манифеста Apple. На других iPhone/прошивках аппаратных испытаний нет.
