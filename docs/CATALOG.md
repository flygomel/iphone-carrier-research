# Экспериментальный экспорт каталога

Статус: код и офлайн-тесты готовы; аппаратный экспорт и возврат ещё не проверены. Это не инструкция активации 5G и не read-only операция: исходный каталог временно перемещается в Media, читается и возвращается.

Поддерживаемый исследовательский профиль строго ограничен iPhone18,2 / iOS 27.2 / 24B5084k. Нужны зависимости из README и собранные helpers:

```bash
make -C vendor/airlift
python catalog.py snapshot --confirmed-device-write
```

Не отключайте кабель и не запускайте синхронизацию Books во время операции. Сценарий сохраняет исходное дерево Books, журнал и состояние в `private/catalog-<token>/`; эти материалы содержат личные данные и не предназначены для публикации.

Результат `phase: complete` означает завершение обмена и совпадение дерева Books. **Он ещё не доказывает точный возврат защищённого каталога.** Для этого нужен второй завершённый экспорт и сравнение файлов/ссылок обоих архивов. Поле `protected_readback_verified` поэтому всегда false. ZIP содержит байты файлов и верхние ссылки; права, владельцы, расширенные атрибуты и пустые папки не сериализуются. Это не полный образ файловой системы.

При прерывании не удаляйте папку запуска и не повторяйте snapshot. Восстановление существующего запуска:

```bash
python catalog.py recover --run private/catalog-<token> --confirmed-device-write
```

Замените `<token>` именем конкретной сохранённой папки. Восстановление проверяет устройство и фиксированный целевой путь. Если исходный экспорт сохранился в Media, сценарий пытается вернуть его; если возврат уже зарегистрирован, восстанавливает Books и удаляет только созданные временные объекты.

Неоднозначные состояния — например, исчезнувший экспорт после тайм-аута возврата или сбой первоначальной подготовки — требуют разбора журнала. Скрипт не считает отсутствие экспорта доказательством успешного возврата и не выполняет слепой повтор. Все варианты аварийного восстановления на реальном телефоне пока не испытаны.

Команд применения изменённого каталога и установки IPCC здесь пока нет. Не используйте экспорт с другого устройства и не переименовывайте candidate ZIP в IPCC.
