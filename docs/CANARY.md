# Первый аппаратный тест

28 сентября 2026 года тест выполнен через этот репозиторий на iPhone18,2 / 24B5084k. Все шесть условий успеха подтвердились. Это не активация 5G и не проверка замены каталога.

## Подготовить на Mac

Из корня репозитория, в установленном Python-окружении:

```bash
make -C vendor/airlift
python -m unittest discover -s tests -v
python carrier.py doctor --out private/before-canary.json
```

Для сборки нужны Apple Command Line Tools и доступные в macOS MobileDevice/AirTrafficHost frameworks. Устанавливать Xcode/CLT автоматически сценарий не будет.

## Что изменит тест

- Создаст случайный файл менее 4 КБ в `/var/mobile/Library/Caches`.
- Временно задействует Books sync и вспомогательные объекты в Media.
- Прочитает тестовый файл обратно, сверит байты и удалит временные объекты.
- Вернёт и проверит шесть отслеживаемых Books sync-файлов. Это не полная копия библиотеки Books.

Операторские пакеты, SIM-привязки и страновые настройки не меняются. Телефон не перезагружается.

Только после согласия владельца на эту операцию:

```bash
python transport_canary.py --confirmed-device-write
```

Скрипт принимает только iPhone18,2 / iOS 27.2 / 24B5084k, подключённый один по USB и уже доверяющий Mac. Совпадение профиля не гарантирует успеха нового теста.

## Оценить результат

Успех требует одновременно:

- размещения временных данных;
- завершения AirTraffic;
- точного совпадения прочитанных байтов;
- отсутствия тестового файла;
- очистки временных объектов;
- восстановления отслеживаемого Books-состояния.

Ответ `ok: true` подтверждает только этот тест. После него пользователь проверяет Books, обычный звонок и мобильные данные. Полная проверка дерева Books потребуется до испытания каталога.

## Если произошла ошибка

Папку `private/canary-...` не удалять и не публиковать: в ней оригинальные Books sync-файлы и привязка устройства. Повторный запуск автоматически блокируется, пока предыдущий журнал не завершён успешно.

Не редактировать журнал ради обхода блокировки. При обрыве операции может понадобиться возврат сохранённых файлов; отдельная проверенная команда восстановления ещё не реализована. Низкоуровневые helpers не предназначены для ручного запуска новичком. Именно поэтому этот тест остаётся этапом подготовки релиза, а не готовым публичным установщиком.
