# Актуальная проверка: 29 сентября 2026, country-only

Основной запуск теперь использует country.py. История прежнего CarrierLab-процесса сохранена в тегах до rc.3 включительно.

- В rc.3 проходили 70 Python-тестов. После удаления старых сценариев их тесты тоже удалены; актуальные проверки перечислены ниже.
- На исследовательском iPhone18,2 / 27.2 / 24B5084k новый открытый исполнитель проверен в режимах inspect, apply и restore. Запись true и точный возврат false подтверждены независимыми последующими экспортами, Books восстановлен, метаданные SIM совпадают до/после. В конце теста исходный файл false.
- Производные байты apply совпадают с проверенным кандидатом; restore берёт точные исходные байты из привязанной к устройству резервной копии, не пересобирает оригинал сериализацией.
- Более ранний в этой сессии минимальный опыт (страновой флаг + перезагрузка, без установки Docomo/CarrierLab) выполнен исследовательским исполнителем. Пользователь подтвердил 5G и сохранение после второй перезагрузки. После первой исходный страновой файл false подтверждён чтением.
- Новый CLI дополнительно не проходил цикл сброса сети и двух пользовательских перезагрузок. Его транспорт, применение и возврат проверены отдельно от пользовательского сетевого результата.
- Устройство ранее участвовало в опытах CarrierLab. Чистый телефон, другие модели/сборки/SIM не проверены.
- Автоматический аварийный возврат при любом обрыве не заявлен. При незавершённом переносе сохраняются журналы, оригинал (если экспорт получен), копии Books; последующие операции блокируются. Ошибки с живой приостановленной сессией пытаются вернуть исходник.
- Firmware/IPCC не загружаются и не устанавливаются новым основным сценарием. Старые режимы сохранены в предыдущих тегах.

## Очистка rc.4

Каталожные операции, установщик IPCC и загрузчики удалены. Неизменённые механизмы переноса, резервирования и проверки Books выделены в file_transport.py; строгая USB-диагностика — в device.py. Возврат исходного странового файла и блокировки незавершённых операций сохранены.

- 30 актуальных Python-тестов проходят: страновой флаг, точный возврат, отказ при неизвестных байтах, резервирование Books, ошибки переноса, старые незавершённые операции и отклонение удалённых CLI-режимов. Native gate tests также проходят.
- В этой очистке телефон не обнаружен по USB, поэтому повторная аппаратная проверка переставленных модулей не выполнена. Аппаратные результаты rc.3 выше относятся к предыдущей структуре кода.
- Локальная папка private, резервные копии, предыдущие релизы и история Git не удалены. Они не входят в новый публичный ZIP.
